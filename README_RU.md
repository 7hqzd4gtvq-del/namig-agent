# 🤖 NaMig AI Agent

**Открытая нейросетевая платформа — любая модель, любые сервисы, полностью бесплатно.**

Скачай → поставь API-ключ → пользуйся. Без подписок, без ограничений.

- 🔌 **Любая модель** — DeepSeek, OpenAI, YandexGPT, GigaChat, OpenRouter и 20+ других из коробки
- 🇷🇺 **Российские сервисы** — Яндекс.Такси, Яндекс.Еда, Яндекс.Маркет, Ozon, Wildberries
- 🧠 **Память и обучение** — агент запоминает контекст, учится на ошибках, сам пишет навыки

- 💻 **Telegram + Терминал** — работай через удобный интерфейс

## 🚀 Быстрый старт

### 1. Установка

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/nousresearch/hermes-agent/main/setup-hermes.sh | bash

# Или через pip
pip install hermes-agent
```

### 2. Настройка

```bash
# Мастер настройки проведёт через всё
hermes setup
```

Выбери провайдера и вставь API-ключ. **Поддерживаются любые ключи** — DeepSeek, OpenAI, YandexGPT, GigaChat, OpenRouter и другие.

### 3. Первая команда

```
Привет! Что ты умеешь?
```

## 🇷🇺 Российские модели

Любой OpenAI-совместимый провайдер работает через custom provider. Просто добавь в `~/.hermes/config.yaml`:

```yaml
custom_providers:
  yandexgpt:
    base_url: https://llm.api.cloud.yandex.net/foundationModels/v1
    api_key: ${YANDEXGPT_API_KEY}
    
  gigachat:
    base_url: https://gigachat.devices.sberbank.ru/api/v1
    api_key: ${GIGACHAT_API_KEY}
```

Или используй любой другой ключ — агент принимает любой OpenAI-совместимый API.
